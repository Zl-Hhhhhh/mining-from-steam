# Group 4｜RQ1–RQ4 研究结果与敏感性汇总

## 可写入报告的结论

1. **玩家谈什么。** 在能识别出主题的评论中，内容与维护、玩法、剧情是主分析里权重最高的三个主题。改变聚类数后，前三项仍是这三类，先后顺序有变化。
2. **哪些主题与推荐相关。** 比较同游戏、同来源语言且游玩时长相近的评论，相对玩法，评论越侧重性能与故障，玩家越少推荐。评论越侧重画面与声音，玩家越常推荐。这两项关联在能估计它们的各项检验中方向一致。
3. **中英文来源评论有何差异。** 在同款游戏内，模型从中文来源评论中识别出的性能与故障、内容与维护权重较高，从英文来源评论中识别出的视听权重较高。中英文的主题检出率也有差异，因此这些发现描述的是已识别的评论内容。
4. **玩得越久是否越常推荐。** 在每款游戏内分组，中时长组比低时长组更常推荐。高时长组和连续时长模型的结果随样本变化，现有证据不足以概括成“玩得越久越推荐”。八个主题也都未在主分析中显示出经多重比较校正的时长差异。

**样本范围。** 50 款游戏共有 19,486 条清洗后评论，其中 4,218 条有主分析可用的主题证据（21.6%）。RQ2 实际比较 49 款游戏的 4,156 条评论，另有一款游戏的 62 条主题评论全部推荐。RQ3 要求同款游戏有足够的双语评论，主题比较用 43 款游戏、3,841 条评论，推荐率和检出率用 48 款游戏。RQ4 的时长与推荐分析直接使用 19,395 条合格评论，其中有主题证据的评论推荐率为 73.8%，其余为 87.3%。

## 核对与复算

- **RQ1** 的主分析、全部片段和高置信度结果取自团队交付表。其余设定用 RQ2 拟合回归前的主题支持表补算。按 `scenario` 分组，将每项 `total_weight` 除以当组八项 `total_weight` 之和，再按比例排序。主设定的权重合计为 4,218，八项比例与 RQ1 原表在报告精度下一致。K=8 通过与 K=10 的片段重叠继承主题映射。[RQ1 原始对照](../output/rq1/topics-v1-exploratory-20261118/sensitivity_overall.csv) · [各设定主题权重](../output/rq2_rq4/topics-v1-exploratory-20261118/rq2_topic_support.csv)
- **RQ2、RQ4** 使用游戏内比较。表中的优势比是两组“推荐概率除以不推荐概率”的比值。区间是逐项 95% 区间，文中校正后的 p 值均用各模型内的 Holm 校正。共同日期、重复文本、每位作者只留一条、排除短评及低信息评论、仅保留采集完整的游戏、换主题方案和极端时长处理均有独立结果行。[RQ2 模型表](../output/rq2_rq4/topics-v1-exploratory-20261118/rq2_models.csv) · [RQ4 模型表](../output/rq2_rq4/topics-v1-exploratory-20261118/rq4_models.csv)
- **RQ3** 的 11 个核心设定主要改变样本、时间窗口或片段范围，另有 3 个设定专门检查主题映射。主主题比较有 43 款游戏，限制共同日期后只有 20 款达到主题比较门槛。跨设定的变化同时可能来自日期和纳入游戏的变化，原表保留了固定这 20 款游戏的对照。[配对结果](../output/rq3/topics-v1-exploratory-20261118/paired_estimates.csv) · [稳健性表](../output/rq3/topics-v1-exploratory-20261118/robustness_summary.csv) · [语言交互模型](../output/rq3/topics-v1-exploratory-20261118/interaction_effects.csv)
