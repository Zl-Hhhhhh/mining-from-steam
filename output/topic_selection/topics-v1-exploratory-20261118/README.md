# topics-v1 cluster-derived

This package provides `topics-v1-exploratory` from `sentence_k10_s42` using the approved topic seeds and cluster-restricted cosine similarity. All sentence units and all review IDs receive an output record. Mixed clusters retain multiple candidate topics or auxiliary routes. The package supports exploratory RQ1, RQ2, RQ3 and RQ4 analysis and remains provisional for final semantic analysis. Review weights are normalized equal contributions across assigned topics, not probabilities. See `rq_usage.md` and `analysis_input_contract.json` before fitting models.
