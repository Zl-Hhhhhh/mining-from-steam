# topics-v1 exploratory 使用说明

## 版本范围

本目录基于批准后的 37 条主题种子、`sentence_k10_s42` 聚类和句子级 BGE 余弦相似度生成。它可用于 RQ1、RQ2、RQ3、RQ4 的探索性分析。

主题权重是句子证据的归一化贡献，不是监督模型输出的概率。`application_only` 单元来自最近簇中心的应用分配，置信度较低。`A01`、`A02` 和 `A03` 不计入主主题比例。

## 主输入文件

- `review_topic_weights.csv` 用于回归、语言比较和游玩时长分析。
- `review_topic_weights.jsonl` 保留每条评论对应的句子单元和主题证据。
- `unit_topic_assignments.jsonl` 用于句子级审查和低置信度筛选。
- `topic_v1.json` 保存主题定义、簇映射、来源哈希和限制条件。

## 主题权重列

- `all_T01`–`all_T08` 包含拟合单元和 `application_only` 单元。
- `fit_T01`–`fit_T08` 只包含 `fit_candidate=true` 单元。
- 主分析建议使用 `fit_T01`–`fit_T08`。
- 使用 `all_` 列作为应用范围敏感性分析。
- 低置信度评论应单独运行敏感性分析，不能静默删除。

## RQ1

使用 `fit_T01`–`fit_T08` 计算总体、游戏、语言和游戏类型的主题权重。报告 `unit_count`、`fit_unit_count`、`application_only_unit_count` 和无主题证据评论数量。

## RQ2

将评论级主题权重按 `review_id` 与推荐结果合并。主题生成没有使用推荐标签。建议模型使用游戏固定效应、语言和主题权重，并将高置信度子集和 `all_` 权重作为敏感性分析。

## RQ3

在同一游戏内比较中英文主题权重。只纳入同时有足够中英文样本的游戏，报告游戏等权和评论加权两种结果。来源语言字段不能单独证明实际文本语言，混合语言和低信息单元需要单独记录。

## RQ4

将评论级主题权重与 `playtime_at_review` 合并。使用 `log1p` 的游玩时长作为连续变量，同时提供分位数组结果。报告缺失时长、重复时长和极端值处理，并比较 `fit_` 与 `all_` 主题权重。

## 必须保留的敏感性分析

1. `fit_` 权重与 `all_` 权重。
2. 全部评论与高置信度评论。
3. `sentence_k10_s42` 与 `sentence_k8_s17` 候选。
4. 包含和排除 `A01`、`A02` 路由单元。
5. 保留和排除 `application_only` 单元。

只有在这些设置下方向一致的结果，才适合作为探索性主发现。当前版本不提供经过独立人工留出集验证的语义准确率，也不支持确认性因果解释。
